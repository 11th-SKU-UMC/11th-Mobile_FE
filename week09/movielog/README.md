# MovieLog · Week09

8주차 MovieLog를 바탕으로 v8 회원·인증·평점 API, 영화 상세의 북마크, 마이페이지의 내 즐겨찾기, 영화 목록 페이지네이션, 영화 검색을 연결했습니다.

## 실행

저장소 루트에서 아래 명령으로 앱을 열 수 있습니다. `.env`에 TMDB Read Access Token을 설정합니다.

```powershell
cd week09/movielog
Copy-Item .env.example .env
flutter pub get
flutter run
```

## 실습과 미션

| 기능 | 확인할 동작 |
| --- | --- |
| 상세 북마크 | 등록·해제 중 버튼이 비활성화되고, 성공 뒤 아이콘과 Snackbar가 갱신됩니다. 이미 등록된 409와 이미 해제된 404는 상태를 다시 조회합니다. |
| 내 즐겨찾기 | 마이페이지에서 목록을 열고, 영화 정보를 `movieId`로 가져옵니다. 일부 실패는 해당 카드에서 재조회합니다. 상세에서 해제하고 돌아오면 목록을 갱신합니다. |
| 영화 목록 | 첫 페이지만 불러오고, 하단에 가까워지면 다음 페이지를 요청합니다. 실패하면 현재 카드를 유지하고 같은 페이지를 다시 요청합니다. 장르를 변경하면 첫 페이지부터 불러옵니다. |
| 영화 검색 | 검색어 제출과 500ms 자동 검색을 지원합니다. 검색 결과에는 더 보기 버튼이 표시됩니다. 빈 검색어는 요청하지 않습니다. |
| 세션 | 사용자별 상태는 `/members/me`로 확인한 이메일과 세션 번호에 묶입니다. `AUTH401_2/3/4`에서 현재 세션을 정리합니다. |
| 평점과 즐겨찾기 | 평점 작성 화면에서 즐겨찾기하지 않은 영화는 체크박스 선택을 포함해 `/v8/movie-records`로 저장합니다. 이미 즐겨찾기한 영화는 `/v8/ratings`로 평점만 등록합니다. 입력 오류나 네트워크 실패 뒤에는 입력을 유지합니다. |

홈의 인기 영화는 기존처럼 최대 5편을 표시합니다. 마이페이지의 평점 목록은 8주차와 동일하게 이번 세션에서 등록한 평점입니다.

## 문법 정리

- `Map`은 즐겨찾기의 `movieId`를 키로 사용해 보충한 TMDB 영화 정보를 찾습니다.
- `Future.wait`는 여러 비동기 작업이 모두 끝날 때까지 기다리고 입력 순서에 맞춰 결과를 반환합니다.
- `record`는 장르 ID 목록과 검색어처럼 관련된 값을 한 값으로 묶습니다.
- `interface`는 구현 클래스가 제공해야 할 메서드의 입력과 반환 타입을 정합니다.
- `mixin`은 `SafeNotify`처럼 여러 클래스에 공통 동작을 추가합니다.
- `ValueKey`는 계정이나 세션 번호가 바뀔 때 Flutter가 화면의 ViewModel을 새로 만들게 합니다.
- 요청 `generation`은 이전 장르나 검색어의 응답이 뒤늦게 도착했을 때 화면에서 무시할 수 있게 합니다.
